# Repository Cleanup for Capstone Submission

## Context

The Talos-CleanRoom repo has accumulated working notes, validation logs, diagnostic outputs, build caches, and planning documents over months of development. The repo is **617 MB** — bloated by terraform provider binaries (122 MB), built documentation site (156 MB), video files (200+ MB), and git history (184 MB). For capstone turn-in we need a clean, professional repo with only the files necessary to understand, build, and deploy the project.

## Guiding Principles

1. **Keep everything needed to build, deploy, and understand the project**
2. **Remove working notes, diagnostic artifacts, and generated files**
3. **Fix .gitignore so removed artifacts don't creep back**
4. **Flag security concerns** (unencrypted credentials)
5. **Don't break git history** — use `git rm` not destructive rewrites
